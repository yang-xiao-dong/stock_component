# 数据接口契约：组件前端拿到的数据格式

> 本文回答三个问题：**传什么、什么类型、什么单位**。字段定义的唯一维护处仍是
> `core/data_define/`（AGENTS.md 约定）；本文是面向前端消费方的格式速查与铁律，
> 改字段流程：先改 data_define → 同步生产端与前端 → 补测试。
>
> 起因：2026-11-02 连环事故——行情解析丢 `float()` 使 high/low 以字符串入库，
> 前端 `.toFixed` 崩溃表现为「连接失败」，且因无类型断言测试而漏网到发布版。
> 类型必须机器守护，不靠自觉。

## 铁律（机器强制，非口头约定）

1. **数值字段一律 JSON number（Python float/int），禁止字符串**。
   腾讯等上游响应全是字符串，生产端（stock_api）负责转换；守护测试：
   `tests/test_stock_api.py::test_quote_numeric_fields_are_floats` 逐字段断言类型。
2. **缺失 = `null`（Python None），禁止 0、"-"、"" 冒充**（0 是合法数值，语义不同）。
3. **单位在契约注释里钉死**：价格=元、成交量=手、成交额=亿元、量比=无量纲。
4. **历史库不可变**：错误数据只能读取侧容错（如 bug 窗口期字符串载荷由前端
   `Number()` 兜底），不得回写修正；新数据自修复之日起自然正确。
5. 前端对任何字段先判 `!= null` 再用；数值参与运算前 `Number()` 容错是允许的
   最后防线，不是生产端的借口。

## 个股组件（components/stock/）三个数据载荷

### get_realtime() → RealtimeQuote（core/data_define/quote.py）

| 字段 | 类型 | 单位/含义 | 空值场景 |
|---|---|---|---|
| name / code | string | 名称 / 腾讯代码（sh603893） | — |
| price / prev_close / open / high / low | **number** | 元 | 停牌等异常 |
| time | string | yyyymmddHHMMSS 市场本地时间 | — |
| change | **number** | 元（涨跌） | |
| change_pct | **number** | %（相对昨收，接口原值直显） | |
| volume | **number** | 手 | |
| amount | **number** | 亿元 | 离线还原行情无此字段 |
| pe_ttm / pe_dynamic / pe_static / pb | **number** | 倍 | 亏损/美股/港股为 null |
| market_cap | **number** | 亿元（美股亿美元） | |
| liang_ratio | **number** | 量比=当日分钟均量÷近5日分钟均量 | 美股无；离线无5日分时；量纲护栏拦截 |

### get_minute_data() → MinutePoint[]（core/data_define/minute.py）

| 字段 | 类型 | 含义 |
|---|---|---|
| time | string | HH:MM |
| price | **number** | 元（该分钟最新价） |
| vol | **number** | **截至该时点的累计成交量（手）**；单分钟量=相邻差分（见 core/vol_calc 口径），不可求和 |
| date | string | 交易日 YYYY-MM-DD（旧快照缺省由数据源补齐） |

### get_kline() → KlineBar[]（core/data_define/kline.py，前复权）

| 字段 | 类型 | 含义 |
|---|---|---|
| date | string | yyyy-mm-dd |
| open / close / high / low | **number** | 元 |
| vol | **number** | 手。2026-11-02 起采集包含；旧行/组合市值蜡烛为 null（不回填），前端对 null 日不画量柱 |

## 组合组件（components/group/）

### get_group_minute() → GroupMinute（core/data_define/group.py）

| 字段 | 类型 | 含义 |
|---|---|---|
| times | string[] | "HH:MM" 序列 |
| total | **number**[]\|null | 组合当日盈亏合计（¥） |
| stocks | StockSeries[] | 各股当日盈亏（¥），色点对应 |
| vol_total | **number**[]\|null | **行业量能**：组内各股单分钟成交量合计（手），与 times 对齐；差分口径同 vol_calc，无量/损坏个股整股不计入 |

### get_group_kline() → GroupKline

principal（¥）、dates、candles（[KlineBar](#get_kline--klinebarcore_data_defineklinepy前复权)，单位¥市值）、
stocks（各股持市值¥线 + bars 各股自身日K）、shares（{code: 建仓份额}）。

## 派生计算口径（core/vol_calc.py，前端 ui.html 内有同口径 JS 版）

- **单分钟量**：累计值相邻差分；任一点无量或负差分累计>末端1% 判数据损坏，量柱整段隐藏。
- **量比**：`当日累计量÷已过分钟数 ÷ (近5日日总量均值÷240)`；结果落在 [0.02,100] 外视为
  量纲混排（旧快照误存成交额），显示 `--`。
