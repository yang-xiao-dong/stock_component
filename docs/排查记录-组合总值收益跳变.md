# 排查记录：组合总值/收益随日K、分时切换跳变

- 修复提交：`aff5462`（fix: 修复日K/分时切换后组合总值与收益跳变）
- 关联文档：[使用说明.md](使用说明.md)「组合口径（本金绝对度量）」一节

## 现象

1. 先点「日K」再点「分时」（或等下一次 5 秒轮询），组合头部「总值 / 累计」整体跳变；
2. 分时标签下显示的**当日收益**比日K标签下**偏高**（组合窗口期内下跌时）；
3. 即使不做任何操作，启动约 10 分钟后数字也会自己跳一次。

## 根因

总值与盈亏都依赖**建仓份额**，而份额曾存在两种口径：

| 口径 | 建仓价 | 生效时机（修复前） |
|---|---|---|
| 近似（旧回退） | 昨收价 | 日K数据未加载期间（启动后前 600 秒） |
| 正式 | 日K窗口（最近 60 个交易日）首日开盘价 | 日K数据落地后 |

触发链路：

1. `group.kline` 定时任务注册时未传 `immediate=True`，首次执行在启动 600 秒后（`REFRESH["kline"]`），此前建仓份额为空；
2. 空档期内 `build_contribution` 按昨收价近似建仓——该口径下**累计盈亏恰好等于当日盈亏**（建仓价=昨收）；
3. 用户点「日K」→ `get_group_kline()` 发现缓存为空 → 同步触发 `refresh_kline()` → 正式份额落地；
4. 下一次概览刷新（点「分时」触发或 5 秒轮询）改用正式份额 → 数字从"近似口径"整体跳成"正式口径"。

**当日收益偏高的原因**：当日盈亏 = 份额 × (现价 − 昨收)，价差相同但份额不同。
近似份额 = 每份本金 ÷ 昨收，正式份额 = 每份本金 ÷ 60 日前开盘。窗口期内下跌的股票
昨收 < 建仓价 → 近似份额更多 → 分时（近似）口径算出的当日盈亏偏大。示例：某股 60 日前
开盘 100 元（正式建仓 100 股），昨收 80 元（近似建仓 125 股），当日涨 1%（现价 80.8）：
正式口径 +80 元，近似口径 +100 元。窗口期内上涨则方向相反。

## 修复内容

| 文件 | 改动 |
|---|---|
| `core/group_calc.py` | `build_contribution` 移除昨收近似回退：建仓数据未就绪时，当日盈亏/持仓市值/总值/累计/收益率一律返回 `None`（前端显示 `--`），只保留涨跌幅与涨跌家数 |
| `components/group/component.py` | ① 日K任务 `immediate=True` 启动即预热，建仓数据几秒内就绪；② `refresh_kline` 改为**合并**份额而非整体覆盖，单只日K偶发抓取失败时保留旧份额，避免二次跳变 |
| `core/data_define/group.py` | 契约中 `day_pnl`/`value`/`total_value` 标注 `Optional`，与"未就绪为 None"口径一致 |
| `tests/test_group_calc.py` | 回退用例改为断言未就绪时字段为 `None` |
| `docs/使用说明.md` | 口径说明同步：加载完成前显示 `--` 而非近似值 |

修复后数字只会「从 `--` 一次性变为正式值」，不再在两种口径之间切换。

## 计算口径备忘

- **模拟建仓**：本金 `config.PRINCIPAL` 均分 N 份，于日K窗口首日以开盘价（前复权）买入、持有不动；每只份额 = 每份本金 ÷ 建仓价，建仓后固定不变；
- **当日盈亏** = 份额 × (现价 − 昨收价)；**累计盈亏** = 份额 × (现价 − 建仓价)；累计收益率 = 累计盈亏 ÷ 本金；
- **窗口滚动**：日K始终取最近 60 根，每个新交易日"建仓日"前移一天——跨交易日后即使股价不动，累计数字也会变，属口径本身、非异常；
- **前复权**消除分红除权跳空，长期累计盈亏不因除权出现假暴跌。
