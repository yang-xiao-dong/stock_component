# 股票小组件（模块化组件版）- 使用说明

## 功能概述
基于 Python + pywebview 的桌面股票小组件，**一个窗口 + 唯一入口**，窗口内切换组件视图；组件各自独立文件、模块化管理。

## 启动（唯一入口）

```bash
cd G:\stock
python app.py
```

启动后是一个置顶无边框悬浮窗：**上方是个股组件、下方是组合组件，窗口内滚动查看**（滚轮在组件卡片空白处会滚动整个窗口；小组件内部的列表如贡献分解仍各自滚动）。两个组件同时实时刷新；**拖动窗口顶部标题栏或任一组件卡片的标题栏移动窗口**，拖窗口边缘缩放。

外壳右上角的「−」将窗口最小化到任务栏，点击任务栏图标即可恢复；「×」关闭整个股票小组件。顶栏在滚动查看组件时保持可见。

> 组件文件仍可单独运行调试（`python -m components.stock.component` 等各开独立窗口），日常使用请以 `python app.py` 为唯一入口。

### 视图1：个股（组件1）
- 滑动/滚轮/点击切换组内股票，查看单只实时行情
- 分时图、日K图，每5秒自动刷新
- 涨跌家数、今开/最高/最低/成交量/成交额

### 视图2：组合（组件2）
把当前股票组视为一个**均分建仓的组合**（口径：比例相对建仓本金，人民币金额为绝对度量）：

- **建仓模型**：本金（`config.PRINCIPAL`，默认 ¥100,000）均分 N 份，于日K窗口首日以开盘价买入，之后持有不动（权重随价格漂移，不再平衡）
- **大字指标**：组合当日盈亏（¥）；副行显示总市值与累计盈亏（¥ 及相对本金百分比）
- **组合分时**：各股当日盈亏（¥）细线 + 白色加粗「组合」合计线，0 轴为当日盈亏基准
- **组合日K**：组合市值（¥）蜡烛 + 各股持市值（¥）细线 + 金色虚线本金基准线
- **盈亏分解**：每只股票显示行情原始涨跌幅（%，相对昨收价）、当日盈亏（¥）和累计盈亏（¥），按当日盈亏降序；色点与图中细线颜色对应。个股涨跌幅直接使用行情接口数值，组合收益率仍相对建仓本金。
- 实时行情一次批量请求获取整组；分时每60秒、日K每10分钟自动刷新

两个视图共享同一窗口的拖动、拖边缩放、置顶能力。

> 组件文件仍可单独运行调试（`python widget.py` / `python widget_group.py` 各开独立窗口），日常使用请以 `python app.py` 为唯一入口。

## 模块化文件结构
```
G:\stock\
├── app.py                  # 唯一入口（薄壳）：自动发现组件并装配启动
├── config.py               # 共享配置：股票组 + 窗口 + 刷新策略（单一配置源）
├── core/                   # 基础层
│   ├── stock_api.py        #   腾讯行情接口（实时/批量/分时/日K）
│   ├── group_calc.py       #   组合均分计算（纯函数，可单测）
│   ├── window_utils.py     #   无边框窗口拖边缩放控制
│   ├── scheduler.py        #   统一后台刷新调度（单线程任务表）
│   └── http_server.py      #   本地静态服务（127.0.0.1，供外壳同源嵌入组件）
├── components/             # 组件层（自动发现）
│   ├── base.py             #   Component 基类 + AppApi 路由 + assemble 装配
│   ├── stock/              #   组件1：个股视图（component.py + ui.html）
│   └── group/              #   组件2：组合视图（component.py + ui.html）
├── assets/                 # 前端共享资源
│   ├── shell.html          #   单窗口外壳：上下堆叠组件 iframe，整体可滚动
│   ├── shared.css          #   卡片/标签/缩放手柄等公共样式
│   └── shared.js           #   桥接/格式化/Canvas 基础/缩放绑定
├── tests/                  # 测试与验证脚本
├── legacy/                 # 历史备份与早期调试脚本（不再维护）
└── docs/使用说明.md        # 本文档
```

### 架构分层
- **入口层** `app.py`：只做"发现组件 → 装配"，无业务逻辑
- **组件层** `components/`：每个组件一个子目录（Component 子类声明 id/标题/界面/API工厂），装配时 API 公共方法挂到窗口 JS 接口，重名冲突启动即报错
- **基础层** `core/`：数据抓取、均分计算、窗口控制、后台调度，组件只调用不实现
- **共享前端** `assets/`：两个界面共用一套基础样式与工具 JS

### 新增组件（零改动接入）
在 `components/` 下新建子目录 `widget_xxx/`：`component.py` 写 `Component` 子类（声明 `id`/`title`，`create_api(scheduler)` 返回 API 对象，用 `scheduler.add()` 注册刷新任务）+ `ui.html`（引入 `../../assets/shared.*`，加「个股/组合」式切换器）。重启即自动出现在切换器里。

组件单独调试（项目根目录下运行）：
```bash
python -m components.stock.component
python -m components.group.component
```

## 组合口径（本金绝对度量）
- **本金建仓**：`config.PRINCIPAL`（默认 ¥100,000）均分 N 份，于日K窗口首日（约60个交易日前）以开盘价买入、持有不动
- **绝对度量（¥）**：组合市值、当日盈亏、累计盈亏、个股持仓市值/盈亏——分时、日K、盈亏分解全部以元计
- **相对度量（%）**：一律相对建仓本金（如 累计盈亏¥ ÷ 本金）
- **近似**：建仓份额加载完成前，当日盈亏按昨收价均分近似；分时某时点缺数据的股票按可得股票合计

## 离线快照
窗口顶部标题栏右侧提供数据模式控制：

- **「存快照」**：抓取当前整组数据（实时行情+分时+日K）保存为当日收盘快照，存于 `data/snapshots/<日期>.json`
- **「离线」**：切换到离线模式，组件整体重载为最近一次快照的数据（数据冻结、不再联网刷新）；出现日期下拉框可切换任意已存交易日
- **「回到在线」**：恢复实时行情；金色「离线 日期」徽标指示当前状态
- **自动保存**：到收盘缓冲时刻（15:05）**主动触发**保存当日快照，完成后再自动布防下一个交易日；启动时若已过收盘时刻会立即补存一次。当日快照已存在则跳过，不重复不覆盖（时刻可在 `config.AUTO_SNAPSHOT` 调整）
- 快照只存原始数据，组合视图（分时/日K/盈亏分解）由快照离线重算，与在线口径完全一致

## 打包为 EXE

发布版本号维护在项目根目录 `version.py`，执行：

```bash
pip install -r requirements-build.txt
python -m builder
```

即可生成 `dist/股票小组件-v<版本>.exe`。这是包含 Python 与项目依赖的单文件程序，可直接复制给其他 Windows 10/11 用户。新增组件会被打包器自动发现，无需修改构建配置。也可用 `python -m builder --version 1.1.0` 临时指定产物版本。

打包版的收盘快照保存在 `%LOCALAPPDATA%\StockWidget\data\snapshots`，不会因 EXE 移动或升级而丢失。目标电脑需要 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已安装）。

自动发布版本从 GitHub 仓库的 Releases 下载 EXE；每累计 5 个 `feat:` 新功能提交，流水线通过测试和打包后会发布下一版本。尚未达到发布数量时，可在 Actions 中下载构建产物。接入步骤、版本与提交计数规则见 [README 的自动打包与发布](../README.md#自动打包与发布github)。

## 注意事项
- 需要网络连接；交易时间外数据不更新（科创板分时会包含盘后固定价格交易时段）
- Windows 需要 Edge WebView2 支持
- 组件以同源 iframe 嵌入外壳（本地 127.0.0.1 静态服务提供页面，桥接自动穿透到父页面）；窗口移动/缩放为**程序化实现**（pointermove 逐步 `move_to`/`resize_to`，pointer capture 防拖出丢帧）：顶部标题栏、卡片间空隙、组件卡片标题栏均可拖动移窗，窗口边缘八向手柄缩放。不用跨线程原生 WM 消息（pywebview 桥接在 worker 线程执行，进不了系统移动/缩放循环）
- `group` 组件页面直接用浏览器打开时显示「演示数据」徽标和随机数据，仅用于界面预览；被外壳嵌入或正常启动时不会出现

## 故障排除
- **数据不更新**：检查网络连接
- **窗口无法显示**：确认 pywebview 已正确安装
- **组合界面显示"等待连接"**：pywebview 桥接未就绪，稍等会自动恢复；超过1.2秒无桥接会进入演示模式（真实启动不会）
