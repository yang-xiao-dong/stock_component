# 瑞芯微（603893.SH）股价桌面小组件

## 方案概述
用 **Python + pywebview** 做一个置顶悬浮小组件窗口，通过**腾讯免费行情接口**获取实时数据，界面用 HTML/CSS/JS 渲染（内嵌，无需外部文件依赖网络）。

## 文件结构（在 G:\stock 下新建）
```
G:\stock\
├── widget.py          # 主程序：启动 pywebview 窗口
├── stock_api.py       # 数据获取：腾讯实时行情 + 当日分时数据
└── ui.html            # 小组件界面（HTML+CSS+原生JS，含Canvas分时图）
```

## 数据源
- **实时行情**：`https://qt.gtimg.cn/q=sh603893`（腾讯接口，免注册，返回当前价、涨跌幅、最高/最低/今开、成交量、成交额等，交易时段约 3-5 秒更新）
- **当日分时**：`https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh603893`（腾讯分时数据，1分钟一个点）

## 实现细节
1. **stock_api.py**
   - `get_realtime()`：解析腾讯行情接口，返回 dict（名称、最新价、涨跌额、涨跌幅、今开、最高、最低、成交量、成交额、时间戳）
   - `get_minute_data()`：返回当日分时序列 `[(time, price), ...]`
   - 用 `requests`，加 Referer 头避免被拒

2. **widget.py**
   - pywebview 创建约 **360×240** 无边框（`frameless=True`）、置顶（`on_top=True`）、半透明背景窗口
   - 通过 `js_api` 暴露 `fetch_data()` 给前端轮询调用
   - 后台线程每 **5 秒**拉取实时行情；分时图每 **60 秒**刷新
   - 支持鼠标拖动窗口（pywebview `drag` 或手动实现）

3. **ui.html**
   - 深色半透明卡片风格，圆角
   - **顶部**：股票名称“瑞芯微 603893” + 数据更新时间
   - **中部**：大字号最新价 + 涨跌额/涨跌幅（涨红跌绿，A股配色）
   - **分时图**：Canvas 绘制当日分时线，带均价线、昨收基准线、渐变填充
   - **底部**：今开 / 最高 / 最低 / 成交量 / 成交额 网格
   - 交易时间外显示“已收盘”状态，仍显示最后一次行情

## 依赖与运行
```
pip install pywebview requests
python widget.py
```
Windows 上 pywebview 使用 EdgeWebView2（Win10/11 一般自带）。

## 验证方式
运行脚本，确认窗口显示、数据每5秒刷新、分时图正常绘制、涨跌配色正确。
